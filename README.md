# Action TWRP Builder

Compila **TWRP** (Team Win Recovery Project) automáticamente usando **GitHub Actions**, sin necesidad de un servidor o máquina local.

> Fork de [husnimbark/Action-TWRP-Builder](https://github.com/husnimbark/Action-TWRP-Builder).

## Requisitos

- Cuenta de GitHub.
- Un árbol de dispositivos TWRP.
- GitHub Actions habilitado en el repositorio.

## Uso

1. Haz fork de este repositorio.
2. Configura las variables y secretos necesarios (fabricante, modelo, etc.).
3. Ejecuta el workflow para compilar la imagen de recuperación.

## Resultado

El workflow genera la imagen de recuperación (`recovery.img`) como artefacto descargable.
